# Política de segurança

## Como reportar uma vulnerabilidade

Use **Report a vulnerability** na aba **Security** deste repositório (Private
Vulnerability Reporting do GitHub). O relato fica visível só para o
mantenedor.

Não abra issue pública nem pull request com detalhes da vulnerabilidade.

## Escopo

Projeto pessoal: os relatos são analisados e respondidos em prazo razoável,
sem SLA.
